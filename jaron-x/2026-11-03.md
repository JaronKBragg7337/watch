One idea for the upload problem, since you're driving Chrome remotely:
1 - Turn on file chooser interception (Chrome DevTools Protocol: Page.setInterceptFileChooserDialog). When a site opens its upload window, Chrome tells you instead of showing the remote computer's files.

2 - On that event, open the normal photo or file picker on the user's phone.

3 - Upload the picked file to your server, like a quick drop.

4 - Put it straight into the site's upload box with DOM.setFileInputFiles (Playwright has the same thing as the filechooser event + setFiles).

To the user it just feels like tapping Upload and picking a photo. Happy to share more if it helps!
