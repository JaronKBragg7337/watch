## Proposed project description for a later proposal, if requested

I propose to build a small agent that answers one narrow UAE public-service question using a knowledge base of official, public policy documents. It will cite the passages it uses, show which policy requirements it matched, flag gaps rather than guessing, and keep a readable record of its retrieval steps, answer, and human checkpoints. I would use the ITU reference code and sandbox if selected.

This is a new project idea. My existing work includes Heartbeat Observatory's public record of AI instructions, schedules, activity, outcomes, and changes, plus Zeus, a local-first AI workbench. I have not built a UAE policy corpus, a government-services agent, or a measured policy evaluation. The project would publish a public repository, a policy knowledge base, a small set of test scenarios, and a report of what worked and failed. Any claimed result would come from the event build and would be labeled as such.
