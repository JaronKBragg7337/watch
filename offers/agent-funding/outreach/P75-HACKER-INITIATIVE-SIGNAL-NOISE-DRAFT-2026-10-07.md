## Draft application text

### Project name

Open Provenance Tools for Local AI Workflows

### Brief project description (150–300 words)

Zeus AI Workbench is a public, MIT-licensed local-first desktop workbench for Ollama models, local files, local retrieval, and desktop tools. One part of it already imports a public repository-map manifest and records the manifest URL, retrieval time, and SHA-256 content hashes in a local provenance file. This is an early feature in one workbench, not a general source-verification system, and the project has no documented outside users yet.

With this grant, I would extend that starting point into a small reusable tool for developers and hacker groups who use local AI. It would keep a record of each public source URL, when it was fetched, and whether its content changed; it would make those records inspectable alongside a generated summary. The work would include tests for missing, duplicated, and changed sources, a small set of public example sources, and plain setup and review instructions. The code and documentation produced for this project would be published under the existing MIT license. The goal is to help a reader see what an AI summary came from and notice when a source has changed, rather than treating a model's summary as proof.

### Project goals and measures of success

1. Add a reusable provenance record and source-change check to Zeus.
2. Add automated examples covering missing, duplicate, and changed sources.
3. Test the tool against a small set of public repository documents and publish the results and setup instructions.
4. Release the funded code and documentation in the MIT-licensed Zeus repository.

These are proposed milestones, not completed work. A start date and delivery dates would be set after an award decision.

### Community benefit

The intended users are independent developers, small open-source teams, and hacker groups who use AI to read public technical material. The current project is operated by Jaron and has no documented outside users or partner group. The proposed tool would be shared in the public Zeus repository so other builders could inspect the source record and reuse or adapt the code.
