## Draft project answers

### Project title

Zeus: a private, local AI workbench with reproducible setup and task records

### Short description

Zeus is an open-source AI workbench that runs with local models and local files. It combines Ollama, local document search, memory, desktop tools, and action logs. I want to make its setup and behavior easier to reproduce and publish clear evidence about what it can and cannot do.

### What problem are you working on?

Many AI tools depend on cloud services, so a person's files and desktop tasks may have to leave their computer, and use may depend on an external account or service. Zeus explores a local-first option that people can inspect and adapt. This is the project's motivation, not a measured claim about customer demand. No outside customer or researcher use is documented today.

### Who could benefit?

The intended users are independent builders and people who want an assistant for local files and desktop tasks while keeping more of the work on their own machine. Researchers and educators may also be able to inspect or adapt an open, reproducible workbench. These are intended audiences; no user or institutional adoption is claimed.

### What would the three-month project do?

This is a proposed plan, not completed work:

1. Document a reproducible local setup and the supported environment for Zeus.
2. Build a small, repeatable evaluation using public or synthetic files to record where local document search and tool workflows succeed or fail. Record limitations and keep private user files out of the evaluation.
3. Improve the documentation and action-history checks where the evaluation shows gaps, then publish the evaluation method and results with the MIT-licensed project.

The initial evaluation can be run by the maintainer. No external testing group is currently documented, so the plan does not depend on one.

### What would the public receive?

The source code is already public under the MIT License. The proposed work would add a reproducible setup guide, a small evaluation method, and a written account of the results and limits, so others can inspect and adapt the work. The project is early; I cannot claim that people currently depend on it.

### Why are you the person to do it?

Jaron K. Bragg is the solo human builder of the public Zeus AI Workbench. The current repository contains a working software effort with local retrieval, desktop tools, local memory, action records, and an experimental model-training path. AI tools assist with research and development. The training path is an experiment, not a finished model. An AI prepared this application draft for Jaron.
