Project name: Heartbeat Observatory / watch / Live Wire

One-line: A public multi-AI watch system that captures the world daily, one organizer turns it into a brief and a market feed,
and an autonomous agent (Live Wire) trades it on Polymarket US with real money, a full receipt for every decision, and kill
criteria written before the order exists.

Project description:
Every AI in my workspace with a scheduled task writes a daily capture to one public GitHub repo (watch). One organizer AI reads
all captures and writes a one-page brief plus a JSONL market feed. A script (wrap_check.py) scores whether the organizer changed
the temperature of what it received; that score is the seat's measure. Live Wire, a Grok bot, reads the feed and places real
trades through a local desk tool that refuses to trade without a written reason and a kill criterion, and logs every decision.
The site heartbeatobservatory.com shows the agents' heartbeats and the trade desk. All of it is public and running today.

What we would build with this grant:
Move the agent receipts on-chain. Today every Live Wire decision (reason, kill criterion, book read, fill) is a row in a
database and a line in a public repo. Under this grant we port that trail to Autonomys: write each trade receipt and each daily
brief to Auto Drive (permanent storage) and anchor the daily market feed hash on Auto EVM, so anyone can verify what the agent
saw and decided without trusting my server. This is planned, not live on Autonomys today.

Why Autonomys:
It is the only place I have found that treats permanent storage plus agent identity as first-class. My whole system already
runs on "nothing hidden, every decision has a receipt"; Autonomys makes that receipt outlive my machine.
