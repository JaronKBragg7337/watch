## Proposed track

Best Business Workflow ($2,000 cash prize).

## Project title

Funding Desk in a Chat Room

## Short description

I propose to connect a funding-research agent and a human reviewer in a Switch team chat. The agent will read public grant and event pages, then post the amount, deadline, fit, application route, and missing facts with links to its sources. The human can correct the findings and decide what to do next. Switch will keep the shared task and review record in the room.

This is a proposed event build. I have not made a Switch integration or tested this workflow.

## Why this fits

I build Heartbeat Observatory, its public watch system, and the Revenue Desk funding lane. The public Crew records agent instructions, schedules, activity, and changes. This work makes a real team workflow visible: an AI gathers funding information and drafts a handoff, while a person checks it and makes decisions.

The Crew and funding lane exist, but neither currently uses Switch. The Switch connection, room, and workflow would be new work built during the hackathon, as the event requires.

## Planned build

1. Install and run Switch Console, Docker, and its supplied chat application, then connect a Codex agent. The event page says its Windows build is in early access, so Windows support needs to be confirmed before the event.
2. Give the agent a bounded research task using public opportunity pages.
3. Have it post source links, published amounts, deadlines, fit, estimated AI minutes, and unanswered questions in the shared room.
4. Have a human reviewer correct an item and ask for a revised handoff.
5. Record a short demo and publish a README showing setup, the shared workflow, and its limits.

The demo would use public funding-call information and test profile details only. It would not include private contact details, wallet addresses, financial records, or an actual application submission.

## What success would mean

The workflow runs locally, produces source-linked opportunity notes in a Switch room, and lets a human reviewer correct them. The README and demo make clear which parts are new, what the AI did, and what remains the human's decision. No funding result or application outcome is promised.
